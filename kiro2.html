Cérebro de Longo Prazo

Agent Steering

Como configurar: Crie a pasta `.kiro/steering` na raiz e adicione arquivos `.md` com o contexto.

# No arquivo .kiro/steering/tech.md
"Sempre use Playwright com TypeScript e siga o padrão Page Object."

Uma vez salvo, o Kiro lerá isso em todas as conversas sem você precisar repetir.

Estratégia

Specs

Como usar: No chat do Kiro, peça para ele criar uma spec baseada em um requisito.

/create-spec baseada no Jira card #123

O Kiro gerará o `requirements.md` e o `design.md` antes de codar.

Reflexos

Agent Hooks

Como ativar: Configure no arquivo `kiro.json` os eventos de gatilho.

"onSave": "npm test current_file"

O Kiro executará a ação toda vez que o gatilho (ex: salvar) for detectado.

Treinamento de Elite

Agent Skills

🛠️ Como usar na prática?

Diferente do Steering (que é passivo), as Skills são ativadas por comando ou mencionadas no prompt.

Opção A: Menção no Prompt
"Kiro, revise este teste usando sua skill de segurança OWASP."
Opção B: Comandos Rápidos (/)
/refactor --skill=clean-code

Exemplo 1: Performance

Ativa análise de tempo de resposta e carga.

/skill performance_test

Exemplo 2: Acessibilidade

Verifica padrões WCAG no seu front-end.

/skill a11y_audit

Por que importa: Quando você ativa uma Skill, o Kiro carrega um "checklist mental" muito mais profundo do que o normal, garantindo que a qualidade técnica seja de nível especialista e não apenas um código funcional.

Onde ficam as Skills?

  • 📍 Nativas: Já vêm no Kiro (Refactor, Doc, Unit Test).
  • 📍 Custom: Você define em arquivos `.kiro/skills/*.md`.

Dica de Pro

Combine Skills! Peça ao Kiro para rodar a Skill de Segurança durante a execução de uma Spec.

Análise de Domínio da IA

Observe que as Agent Skills possuem o maior nível de "Especialização". Enquanto o Steering provê a base (Consistência), as Skills são o topo da pirâmide de qualidade técnica.
