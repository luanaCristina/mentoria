Cérebro de Longo Prazo

Agent Steering

A Analogia: O Manual de Onboarding

É o documento que você entrega no primeiro dia: "Aqui usamos Node.js, nossa arquitetura é X e seguimos o padrão EARS".

Arquivos: .kiro/steering/product.md, tech.md

Por que importa: Sem ele, a IA tem amnésia. Com ele, o Kiro tem memória permanente das suas regras de negócio e cultura de engenharia.

Configurações Globais:

  • ✓ Regras de Linguagem
  • ✓ Padrões de Projeto
  • ✓ Contexto de Negócio
  • ✓ Estrutura de Pastas
Estratégia de Execução

Specs

A Analogia: O Plano de Voo da Sprint

É a sessão de refinamento (Planning). Antes de codar, o engenheiro desenha os critérios de aceitação e a lista de tarefas.

Fluxo: requirements.md ➔ design.md ➔ tasks.md

Por que importa: Evita o "código solto". O Kiro planeja sistematicamente e executa via subagentes focados em tarefas reais.

Passo a Passo:

  • 1. Definir Requisitos
  • 2. Desenhar Arquitetura
  • 3. Listar Tasks de Código
  • 4. Execução Assistida
Automação Reativa

Agent Hooks

A Analogia: Os Reflexos Automáticos

Sempre que o engenheiro salva um arquivo (Ctrl+S), ele roda o linter ou os testes unitários por puro hábito e reflexo.

Configuração: JSON / Gatilhos na IDE

Por que importa: Previne bugs bobos e traz agilidade extrema. A IDE reage ao seu comportamento e valida o código no mesmo segundo.

Gatilhos Comuns:

  • ⚡ Salvar Arquivo
  • ⚡ Criar Nova Classe
  • ⚡ Antes do Commit
  • ⚡ Abrir a IDE
Treinamento de Elite

Agent Skills

A Analogia: As Certificações Especialistas

É quando você diz: "Agora precisamos auditar a segurança". O engenheiro ativa o modo especialista com checklists de OWASP e performance.

Comando: Ativado sob demanda

Por que importa: Permite versatilidade. O Kiro vira um especialista em segurança, performance ou refatoração no momento exato da solicitação.

Skills de Sucesso:

  • ★ Refatoração Avançada
  • ★ Segurança (OWASP)
  • ★ Testes de Carga
  • ★ Acessibilidade (WCAG)
